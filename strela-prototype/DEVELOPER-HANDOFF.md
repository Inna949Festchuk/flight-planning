# СТРЕЛА — передача разработчику

## Запуск

В PowerShell из папки проекта:

```powershell
.\start-prototype.ps1
```

Открыть `http://127.0.0.1:4173`.

## Структура

- `index.html` — точка входа.
- `prototype.js` — состояния, HTML-компоненты и переходы сценария.
- `prototype.css` — дизайн-токены, сетки и стили всех экранов.
- `public/assets/strela-logo.png` — логотип.
- `public/assets/setup-loaded.png` — единственный растровый фрагмент интерфейса: карта.

## Сценарий

1. Вход по `demo / demo` (проверка данных намеренно не блокирует демо).
2. Загрузка точек и области кликом по карточкам.
3. Просмотр 56 БВС, закрытие панели через «Скрыть» или крестик, исключение и возврат аппарата через меню `•••`.
4. Расчёт и просмотр трёх вариантов.
5. Постоянно доступные действия скачивания и выбора; раскрытие состава работ — отдельно.
6. Выбор варианта или скачивание текстового полётного задания.
7. Финальное модальное окно поверх результатов.

## Данные для интеграции

Текущие массивы `routes` и `droneList` в `prototype.js` заменяются ответами API без изменения разметки. Состояния загрузки, исключения БВС и выбранного маршрута собраны в объекте `state`. Карта намеренно статична; её можно заменить SDK карты внутри `.map-surface`.

## Дизайн-токены

Основные цвета определены CSS-переменными в начале `prototype.css`. Целевой макет — desktop 1920×1080; предусмотрено компактное поведение до 1080 px ширины.
