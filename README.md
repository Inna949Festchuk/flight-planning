# Кейс 15 · Сервис планирования и распределения беспилотных авиационных работ

## drone_planner (АЛГОРИТМ ПОСЛЕДНЯЯ ВЕРСИЯ)

В папке [`drone_planner`](./drone_planner/) лежит отдельный планировщик съёмки. Он назначает конкретные борта со своих ВПП на районы, строит галсы в обход запретных зон и считает три варианта плана: минимальное время, минимальный ресурс и баланс времени с ресурсом. Результат можно смотреть на карте в браузере или получить из консоли.

**Запуск.** Читайте [drone_planner/README.md](./drone_planner/README.md), раздел «Развёртывание». Оттуда же: `cd drone_planner`, затем `.\start.bat`. Карта откроется на [http://127.0.0.1:8765](http://127.0.0.1:8765).

**Алгоритм.** Как идёт расчёт, читайте в [drone_planner/Алгоритм.md](./drone_planner/Алгоритм.md): парк и камеры, назначение бортов, делёж площади, выбор плана и маршрут вокруг запретных зон.
